* 神經網路架構分析 (Neural Network Architecture Analysis)

** 全連接層 (Fully Connected Layers)
此專案 (`ac_solver/agents/ppo_agent.py`) 使用全連接層 (`nn.Linear`)。
數學公式：$y = \sigma(Wx + b)$。
- $W$: 權重矩陣 (Weight matrix)。
- $b$: 偏差向量 (Bias vector)。
- 第 $N$ 層的每個神經元都與第 $N+1$ 層的每個神經元相連。
- 初始化：使用正交初始化 (Orthogonal Initialization)，隱藏層標準差為 $\sqrt{2}$。

** 網路拓撲與形狀 (Network Topology and Shapes)
The architecture is a Multi-Layer Perceptron (MLP) dynamically determined by the `nodes_counts` parameter.
Both Actor and Critic share the same structure for hidden layers but differ in the final output layer.

Definitions:
- **Input_Dim**: The size of the flattened observation vector. In the AC Solver context, this represents the state of the presentation (the relators). It is calculated as `num_relators * max_relator_length`.
- **nodes_counts**: A list of integers (hyperparameters) defining the width of the hidden layers. For example, `[64, 64]` means two hidden layers, each with 64 neurons.

Structure defined by `build_network`:
1. **Input Layer**: Linear(Input_Dim, nodes_counts[0]) followed by Tanh activation.
2. **Hidden Layers**: For each subsequent layer, Linear(nodes_counts[i], nodes_counts[i+1]) followed by Tanh activation.
3. **Output Layer**:
   - **Critic**: Linear(nodes_counts[-1], 1). Outputs scalar value $V(s)$.
   - **Actor**: Linear(nodes_counts[-1], Action_Space_Size). Outputs action logits.

Example: If `nodes_counts` (hidden sizes) is `[64, 64]`:
- Layer 1: Linear(Input, 64) -> Tanh
- Layer 2: Linear(64, 64) -> Tanh
- Layer 3: Linear(64, Output)

** 激活函數：Tanh vs ReLU
實作中使用 `nn.Tanh()` 而非 `nn.ReLU()`。
- 範圍：Tanh 映射至 (-1, 1)，有助於對稱的動作分佈。
- 平滑度：Tanh 是 $C^2$ 連續的，為策略優化提供穩定的二階梯度。
- 穩定性：避免了神經元輸出恆為零的 "Dying ReLU" 問題。

* 透過 SAE 進行機械可解釋性 (Mechanistic Interpretability via SAE)

** 特徵操縱邏輯 (Feature Steering Logic)
SAE (稀疏自動編碼器) 允許我們操縱求解器的直覺。
1. 從倒數第二層 (即 `actor_body` 的輸出) 提取激活值 $f$。
2. 將 $f$ 映射到稀疏特徵 $z$：$z = \text{ReLU}(W_{enc} \cdot f + b_{enc})$。
3. 手動擾動特定特徵 $z_i$ (例如：增加其強度)。
4. 重建修改後的激活值 $f' = W_{dec} \cdot z' + b_{dec}$。
5. 將 $f'$ 傳入 Actor Head (`actor_head`) 以觀察行為變化。

** 為何針對 Actor 網路？
- Actor：專注於策略 (決策邏輯)。
- Critic：專注於價值估計 (狀態品質評估)。
- 解釋 Actor 可以揭示特定移動/動作背後的「原因」。

* 實作與重構筆記 (Implementation and Refactoring Notes)

** 重構策略 (Refactoring Strategy)
目前的程式碼 (`ac_solver/agents/ppo_agent.py`) 已經將 Actor 區塊拆分，以隔離特徵提取與決策頭：
- `actor_body`：包含線性層和 Tanh 激活函數，直到最後一個隱藏層。這就是我們要提取 SAE 訓練數據的地方。
- `actor_head`：最後一個線性層，將特徵映射到動作 logits。
- 新增了 `get_actor_activations(x)` 方法來方便提取。

** 權重兼容性 (Weight Compatibility)
- 如果載入舊的檢查點 (checkpoint)，需要映射 `state_dict` 的鍵值。
- 例如：將原本的 `actor.layer_idx.weight` 映射到 `actor_body.layer_idx.weight` 或 `actor_head.weight`。

** 常見 ML 架構替代方案
- 卷積神經網路 (CNN)：適用於空間/圖像基礎的觀察 (此專案未使用)。
- 遞歸神經網路 (RNN/LSTM)：適用於時間依賴性和 POMDPs。
- Transformer：適用於全域注意力機制和長距離依賴。
